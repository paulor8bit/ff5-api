# Final Fantasy V Sprite Images

This folder contains placeholder sprites for the FF5 API project.

## Folder Structure

- `characters/` - Main character battle sprites (Bartz, Lenna, Galuf, Faris, Krile)
- `jobs/` - Job class sprites (Knight, Monk, Black Mage, etc.)
- `monsters/` - Monster and boss sprites

## File Naming Convention

- Characters: `char_XXX_name.png`
- Jobs: `job_XXX_name.png`
- Monsters: `monster_XXX_name.png`
- Items: `item_XXX_name.png`
